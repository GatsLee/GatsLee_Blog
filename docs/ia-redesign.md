# IA 개편 — 동선 정리

실측과 DB 확인에서 드러난 죽은 동선을 정리한 기록. Figma web을 먼저 반영하고, 모바일 → 로컬 코드 → 배포 순으로 이어간다.

기준 일자: 2026-09-07

## 문제

| # | 문제 | 근거 |
|---|------|------|
| 1 | 케이스 스터디 글이 **0건**인데 네비 2번째이자 히어로 주 CTA의 목적지 | `post` 테이블에 `category='case'` 0행 |
| 2 | `build` 카테고리 **10건에 목록 페이지가 없다** | `/insights`는 `category='journal'`만 조회. build는 홈 위젯에서만 노출되고 상세는 `/insights/[slug]`로 열린다 |
| 3 | 네비 라벨과 카테고리 이름이 교차 | 네비 "빌드" = `/products`(product+agent), 카테고리 `build`는 별개 |
| 4 | 커넥트·케이스 모두 빈 상태 | 방문자가 두 번 연속 빈 화면을 만난다 |
| 5 | 이력서에 `경험 항목이 비어 있습니다` 플레이스홀더 노출 | 프로덕션 화면 |

## 결정한 IA

네비 6개 → **5개**. 케이스 스터디는 실제 글이 생길 때 다시 넣는다.

| 순서 | 라벨 | 라우트 | 내용 |
|------|------|--------|------|
| 1 | 홈 | `/` | — |
| 2 | 만든 것 | `/products` | 프로덕트 3 + 에이전트 3 = 6 |
| 3 | 기록 | `/insights` | 저널 13 + 빌드 로그 10 = 23 |
| 4 | 이력서 | `/resume` | — |
| 5 | 소개 | `/about` | — |

- 히어로 CTA: `케이스 스터디 보기` → **`만든 것 보기`**
- 홈 섹션명: `빌더 로그` → **`기록`**, `진행 중인 프로젝트` → **`만든 것`**
- 기록 목록에 **유형 필터**(ALL 23 / 저널 13 / 빌드 로그 10)와 행별 **유형 칩** 추가 — build 글이 처음으로 목록에 오른다
- 커넥트 빈 상태에 대체 동선 버튼(이력서 보기 / 만든 것 보기 / GitHub)

## 코드에 반영할 것 (다음 단계)

- `src/components/layout/TopNav.tsx` — `navItems`에서 `/cases` 제거, 라벨 `products`→만든 것, `insights`→기록
- `src/i18n/translations.ts` — `nav.products`, `nav.insights` 라벨 교체 (ko/en)
- `src/app/insights/page.tsx` — `category: "journal"` → `category: { in: ["journal","build"] }`
- `src/app/insights/InsightsList.tsx` — 유형 필터 탭과 행 유형 칩 추가
- `src/app/page.tsx` — 히어로 CTA 링크·라벨, 섹션 제목
- `src/lib/categories.ts` — `case` 라우트는 유지(글이 생기면 복원), 네비에서만 제외
- `/cases` 라우트 처리 — 유지하되 네비 비노출

## 남겨둔 것

홈 서버 패널이 `RAM 100% · DISK 100%` 빨간 바에 `CONTAINERS 0 active`를 함께 보여준다. 바로 위 히어로는 "99%+ 가동률"을 주장한다. 프로덕션 홈서버에는 컨테이너 18개가 실제로 돌고 있으므로 지표 수집 쪽 문제일 가능성이 있다. 이번 IA 작업 범위 밖이라 별건으로 둔다.

## 히어로 3D 오브젝트

히어로 우측 480×380 영역. 와이어프레임에서는 점선 박스로 자리만 잡아 두고, 구현 단계에서 채운다.

**방식: three.js 프리미티브 조합 + 와이어프레임 렌더 (모델 파일 없음)**

| 항목 | 결정 |
|------|------|
| 대상 | VR 기기 · 스마트폰 · 모니터 3종 순환 |
| 지오메트리 | `BoxGeometry`·`CylinderGeometry` 등 프리미티브 조합으로 형태만 구성. GLB 에셋 미사용 |
| 재질 | `MeshBasicMaterial` + `wireframe: true`. 반사·금속 없음 |
| 이유 | "종이는 빛나지 않는다" 원칙. 반사 재질은 컨셉과 충돌한다. 에셋이 없어 용량도 최소 |
| 전환 | 6~8초 주기 교체, 스케일·투명도 크로스페이드 |
| 로딩 | `dynamic(() => import(...), { ssr: false })`. 하이드레이션 이후 로드, 그전에는 정적 SVG 큐브 |
| 접근성 | `prefers-reduced-motion`이면 회전 정지, 한 형태만 표시 |
| 성능 | 모바일 DPR 1.5 상한, 프레임 30fps 제한 |

색은 괘선 색(`#E8E3D8`)과 연필 색(`#6E6A5F`) 사이에서 잡아 종이에 그린 도면처럼 보이게 한다.
