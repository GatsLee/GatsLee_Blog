Figma 상세기획 파일의 섹션·화면 배치 기록. **`wireframe(web)`은 사용자가 직접 정리한 상태이므로 이 좌표를 정본으로 삼는다.** 자동 재배치 금지.

기록 시각: 2026-09-07 / File Key `wsLPU5JDsN67AAutcUBGeO`

## 좌표계 주의

Figma **섹션의 자식 프레임은 섹션 기준 상대 좌표**를 쓴다. 페이지 절대 좌표가 아니다.

```js
// 잘못된 방식 — 절대 좌표를 써 넣으면 프레임이 섹션 밖으로 밀려난다
k.x = sectionX + 100;

// 올바른 방식 — 섹션 안쪽 기준
k.x = 100;
```

또한 **섹션을 옮기면 자식도 함께 이동한다.** 섹션 위치를 바꿀 일이 있으면 섹션만 옮기고 자식 좌표는 건드리지 않는다.
